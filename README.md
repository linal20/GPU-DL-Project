This projects is for the paper "Use Deep Learning Models to Predict Failure Status and Remaining Life of GPU"

* **GPU_dat.csv**: Dataset used for the analysis.
* **ML_functions**: Functions used for the machine learning models.
* **metrics_functions**: Functions for calculating classification and regression evaluation metrics.
* **ML_hyperparam_optim_cv**: Cross-validation procedure for hyperparameter optimization of the machine learning models.
* **NN_hyperparam_optim_cv**: Cross-validation procedure for hyperparameter optimization of the neural network models.
